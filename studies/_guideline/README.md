# 手引の定数のファイル

このフォルダのファイル（`<名前>.json`）は、計算の基準になる値（強度式、放流の係数など）を書いたものです。
study.json の `guideline`（必須）に名前か .json のパス（検討フォルダから見た相対パスか絶対パス）を書くか、WebGUI の「手引の定数」で選んで使います。

| ファイル | 内容 |
| --- | --- |
| `chiba_2006.json` | 千葉県における宅地開発等に伴う雨水排水・貯留浸透計画策定の手引（平成18年9月） |
| `_template.json` | 他の基準のファイルを作るための雛形。名前が `_` で始まるファイルは、WebGUI の選択肢に出ません |

## 他の基準のファイルを作る

1. `_template.json` をコピーし、基準が分かる名前（`<都道府県>_<年>.json` など）にして、このフォルダに保存します
2. 値を、使用する基準の値に書き換えます
3. `uv run amamizu verify --guideline <名前>` で、強度式の係数が基準の表の値と合うかを確かめます（`formula_table` に書いた表の値と照合します）
4. study.json の `guideline` に名前か .json のパスを書くか、WebGUI の「手引の定数」で選びます

ファイルを作らずに計算することもできます。WebGUI の「手引の定数」で「使用しない」を選び、放流の係数と強度式の係数を入力します
（study.json では `"guideline": null` と `hydraulics`）。
`null` は設計の検討（kind: design）だけで使えます。手引の定数を選んだ検討に `hydraulics` を書くとエラーになります。

## 項目

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| `name` | ○ | 基準の名前。WebGUI、`amamizu verify` の表示、エラーの文に使う |
| `hydraulics` | ○ | 放流の係数。`g` は重力加速度 m/s^2、`c_weir` は越流係数、`c_orifice` はオリフィスの流量係数 |
| `formulas` | ○ | 地区 → 確率年 → `[a, n, b]`。強度式 r＝a/(t^n＋b) の係数。r は mm/h、t は分。n は `"3/4"` のような分数の文字列でもよい |
| `formula_table` | ○ | 地区 → 確率年 → `[10分, 60分, 1440分]` の降雨強度 mm/h。基準の表の値を書く。`amamizu verify` が式の値と照合する |
| `default_district` | | WebGUI で計画降雨を選ぶときの地区の初期値。なければ `formulas` の最初の地区 |
| `district_term` | | 強度式を分ける区域の呼び方。なければ「地区」 |
| `qc_min`、`runoff`、`district_of_station` | | 貯留施設の検証、降雨強度の検証に使う。貯留追跡計算だけなら書かなくてよい |
| `hayami` など、`infiltration_table` など | | 基準の早見表。`amamizu verify` で計算結果と比べる。なければ書かない |
| `infiltration_notes` | | WebGUI の浸透施設の欄の近くに表示する文（`factors` 影響係数、`void` 空隙貯留量）。なければ書かない |
| `region`、`issuer`、`citation`、`cite` | | レポートの文に使う語。レポートを作る検討に必要 |
| `…_note` | | 項目の説明（メモ）。計算に影響しない |

ファイルを読み込むときに、書いた項目の形（数か文字列か、リストの値の数、表どうしの行の数など）を確かめます。違っていれば、場所を示してエラーで止まります。

項目ごとの使い道は `docs/条件設定.md` の「手引の定数」にあります。

## 書ける範囲

| 基準の規定 | 書けるか |
| --- | --- |
| タルボット式 a/(t＋b) | 書ける。n を 1 にする |
| シャーマン式 a/t^n | 書ける。b を 0 にする |
| 久野・石黒式 a/(√t±b) | 書ける。n を `"1/2"` にする。a/(√t－b) は b を負の値にする |
| クリーブランド式 a/(t^n＋b) | 書ける |
| 継続時間の範囲で式が変わる強度式 | 書けない。1つの地区と確率年に、式は1つ |
| 日雨量から求める強度式、t の単位が時間の式 | 書けない |

計画降雨の波形（後方集中型、中央集中型）、合理式による流出量、オリフィスの式の切り替えの水深（高さの1.2倍と1.8倍）は、
計算の方法として決まっていて、このファイルでは変えられません。

強度式を書けない基準では、計画降雨を別に作り、降雨の表かハイドログラフを流入に使います。
