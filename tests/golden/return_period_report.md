# 県の手引きによる降雨強度の検証

この検討の計算を、千葉県の観測所18地点ごとに示す。

標本は気象庁が公表する年最大10分間降水量（mm）をそのまま使う。
標本には、資料不足値（`]`）が 20 個含まれる。
県の10年確率式の値は mm/hr なので、6で割って mm/10分 に直し、その値の再現期間を読む。
継続時間は10分とする。

年最大10分間降水量にグンベル分布をモーメント法で算定した。
標本は2026年と部分年を除く。

地点の並びは、地区の10年確率式の値の再現期間が短い順とする。
上にあるほど、その地点の準拠基準が名乗る10年確率に対して実際の頻度が高い。
